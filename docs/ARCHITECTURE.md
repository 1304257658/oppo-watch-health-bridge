# 架构、状态与后续验收

## 预期链路（尚未全部实现）

1. 手表向已配对手机同步
2. 手机应用将用户授权范围内的数据同步到账号云端
3. 独立云端客户端通过受支持的私密认证流程取得最小访问能力
4. 客户端只读取约定范围，输出最少结果
5. 独立验证到期、撤销和续期，再考虑调度

MCP 只是工具调用接口，不等于认证，不会让 token 自动永久有效。

## 此仓库实际实现

合成 Material → 固定 endpoint/十分钟测试时间窗 → 排序头字段与 HMAC-SHA256 格式演练 → FakeTransport/注入模拟连接 → 白名单结果。

这些协议字段是版本相关研究观察，不是官方兼容性承诺。HMAC 密钥和应用 ID 为合成占位值，故公开快照不能复现真实签名。默认传输没有外部网络工厂；默认命令和真实命令均不能访问真实账号。

回环表单有精确 Host/Origin 校验、随机 CSRF、单次消费、五分钟超时、请求体上限、不记录表单、禁止外部资源和嵌入。它只接受固定假数据。不要将它暴露到公网或改成实际凭证保管服务。

## 安全与测试边界

- 目标与请求体/时间窗精确匹配；实例最多一次尝试，失败不自动重试
- 设计上验证 TLS、禁止重定向、限制响应体、禁止诊断回显
- 测试通过注入模拟连接验证传输逻辑；没有与真实服务器握手
- 结果只保留状态码与记录存在标志，不保存健康明细
- Python 可变缓冲区覆盖仅尽力清理；不可保证不可变副本、浏览器、交换区或系统崩溃转储被擦除

## 待完成验收

1. 运行环境生命周期、持久性、外网出口与依赖明确可用
2. 认证交接的接收方、字段、用途、时长、撤销和保管方式获得具体授权；用户本人完成敏感交接
3. 本地电脑和模拟器独立确认关闭后，云端完成一次限定读取；仅保留脱敏状态结果
4. 单独论证并验证续期协议、最少字段、过期错误、撤销、多实例并发与轮换恢复
5. 经用户授权再配置适当采集频率、最小数据保存与告警；不能先承诺永远在线

本仓库可作为云环境的源码起点，但不是上述验收已经通过的证明。
