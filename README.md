# OPPO Watch Health Bridge

OPPO Watch S / OPPO 健康个人数据互操作实验的**脱敏、离线研究骨架**。

本仓库保存可复现的合成数据测试与踩坑经验，不是官方 SDK，也不是已经上线的健康数据服务。它不能直接登录账号或读取真实健康数据。

## 当前状态

- 经用户亲自操作，独立的本地实验完成过一次限定时间段的步数只读请求，服务端成功返回且存在记录
- 本次公开版本重新脱敏后，**58 项测试通过**；仅使用合成数据、模拟连接或本机回环 HTTP
- 私有实验曾有 61 项离线测试；本公开快照删除了待激活的真实表单与重复打包代码，增加了公开版禁用检查，因此数量不同
- 云端真实读取、凭证自动续期、模拟器关闭后的长期运行，均**尚未验证**
- 云端桌面的外网请求在本次探测中被拒绝；本机回环页面成功不代表外网或长期运行可用

## 快速开始

Python 3.10+，无第三方依赖；验证环境为 Python 3.12。

```sh
python -m unittest -q
python cloud_main.py --dry-run
```

输出中的 HTTP 200、业务状态和记录存在标志都是**模拟值**，不是服务端证据。

可选启动假数据表单：

```sh
python loopback_form.py
```

它仅监听 127.0.0.1 随机端口，页面只接受明示的假数据，一次提交或五分钟后结束。不要输入真实凭证；远程环境的回环地址也不一定能从你的浏览器访问。

`python cloud_main.py --live` 会关闭失败，不读取凭证、不访问网络。默认 `Transport` 不带网络工厂，不能建立外部连接。签名密钥与 app ID 已替换为明显的合成值；仓库不包含恢复厂商签名材料的步骤。

## 目录

- `core.py`：限定目标和时间窗、签名规范演练、单次传输抽象、结果脱敏
- `cloud_main.py`：默认离线、真实入口关闭
- `main.py`：原本地流程的交互与清理结构参考；未附模拟器访问模块
- `loopback_form.py`：只接受假数据的短生命周期回环页面
- `test_*.py`：离线协议、错误路径、恢复状态、表单与公开版禁用测试

## 范围

当前实验限定步数记录存在性，不提供心率、睡眠等全部指标的可靠采集，也不用于诊断或实时急救监测。不要把本仓库当成获取他人账号数据、绕过服务端授权或修改健康记录的工具。

后续需解决受支持的私密登录交接、可用云端网络、最小化授权保存与撤销、单次真实读取验收，再单独验证续期。建立 GitHub 仓库或连接运行环境本身不会解决这些问题。

本项目与 OPPO / HeyTap 无隶属或背书关系。公开技术观察会随应用版本和服务端策略变化。
